# A.T.L.A.S — Advanced Tactical Leadership & Administration System

A geopolitical strategy game: lead any country from 1 January 2010. Run its economy, budget, industry and trade; manage diplomacy, the UN, intelligence and wars; deal with disasters, approval and population.

## Play

- **Android:** download [ATLAS.apk](https://github.com/IronMuttz/Project-A.T.L.A.S/raw/main/ATLAS.apk) and open it on your phone. Allow installs from the app you opened it with, and tap *Install anyway* if Play Protect warns about an unknown developer. The app updates itself: when a new version is out it offers to restart into it, and your saves are kept.
- **iPhone / iPad / any browser:** open https://ironmuttz.github.io/Project-A.T.L.A.S/ (once GitHub Pages is on). On iPhone or iPad tap *Share → Add to Home Screen* to play it full screen like an app.

Saves are stored on each device. To move a game between devices use ☰ → Save / Load → Export, then Import on the other device.

## Files

| File | What it is |
|---|---|
| `index.html` | The whole game in one file (works offline once loaded) |
| `version.json` | The current version number; the Android app checks it to update itself |
| `ATLAS.apk` | The Android app |
